RemoteCare CLI

A simple, command-line tool to manage medical emergencies in rural areas.

Features

  • Log emergencies
  • Prioritize cases
  • Access first aid guides

How to Use

        # Clone the repository
        git clone https://github.com/your-username/remotecare.git
        cd remotecare
        
        # Run the CLI tool
        cargo run -- help
